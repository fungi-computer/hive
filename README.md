# hive

The HIVE MVP — a plain Pixi.js + Vite prototype. Colored squares only.

**The whole game (two states):** SETTLED = sitting with the group. EXECUTING = beside a tree.

A deterministic in-page ticker (emulates BirdDog; wired to nothing real — testing POC) sends colonists to their trees and back. The referee line prints the ledger: plain numbers.

Run: `npm install && npm run dev` → http://localhost:5173
