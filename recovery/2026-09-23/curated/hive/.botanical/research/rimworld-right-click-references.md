# RimWorld right-click references — source-observed 2026-09-07

Sources are mod-author material, not an unmodded RimWorld manual: [Achtung! source](https://github.com/pardeike/Achtung2/blob/master/Source/Controller.cs), its [author workshop description](https://steamcommunity.com/sharedfiles/filedetails/?id=730936602), and [Allow Tool’s author repository](https://github.com/UnlimitedHugs/RimworldAllowTool). I did not run RimWorld or either mod. Achtung is a configurable, current-RimWorld mod; its menu modes, formations, and forced-job persistence are evidence for interaction tradeoffs, not controls Hive should reproduce. Allow Tool’s public README establishes bulk allow/select-similar/urgent-haul intent but not a complete right-click specification.

1. **Selection is a set; Draft is an execution gate.** Achtung’s source distinguishes an all-drafted selection, a mixed selection, and no selection before choosing right-click behavior. Its mixed-draft contract verifies that an ordinary command moves the drafted unit while leaving a selected undrafted labor unit undrafted and without a forced GoTo job ([controller](https://github.com/pardeike/Achtung2/blob/master/Source/Controller.cs), [contract](https://github.com/pardeike/Achtung2/blob/master/TESTING.md)). Carry that rule into the accepted Hive **Work → Draft/Go** control: selecting Rowan and Sedge remains inspection/command targeting; Draft explicitly makes a home member eligible for Go. Do not make Recruit, selection, or a direct Work request silently draft a person. Use the existing selection/action path; Draft state belongs with authoritative actor facts when it exists, not another UI store.

2. **Give right-click one immediate default only when the state and target are unambiguous.** Achtung checks that every selected colonist is drafted and that the clicked cell is a valid plain move before beginning positioning; its configurable modes otherwise surface a menu, modifier, or long-press path ([controller](https://github.com/pardeike/Achtung2/blob/master/Source/Controller.cs)). For Hive: with one-or-more drafted home members and clear walkable ground, right-click can issue **Go** immediately. With an undrafted or mixed selection, or on an actor/tree/site, right-click should open a compact context choice such as **Work**, **Go**, or the target-specific action; it should not guess and interrupt work. Keep the selected people selected after either outcome and show the submitted target/receipt. This is a Hive recommendation; the cited source does not prove a universal RimWorld default for every version or mod setup.

3. **Name normal Work and persistent forced work differently, and give the latter a visible stop.** Achtung places a force button inside the context menu, marks forced targets, says the work is uninterrupted, and provides a normal clear path; its author warns these jobs are aggressive rather than soft scheduling ([workshop description](https://steamcommunity.com/sharedfiles/filedetails/?id=730936602), [README](https://github.com/pardeike/Achtung2)). Hive’s current `direct: true` already interrupts in-scope people and front-loads a job (`orders.ts:79-128`), while ordinary shared Chop has `actors: null` (`main.js:175-188`). Present those as **Work selected** versus **Shared designation** now. Reserve an explicit **Force until done / Clear forced work** status only for a later authoritative persistent override, with target IDs and completion/cancellation feedback. Do not call every normal Work click a force command.

4. **Keep modifier meanings stable: Shift adds to selection today; queue needs a visible ordered plan later.** Achtung’s author description says forced targets can be added without Shift “like ordinary jobs,” while its controller explicitly retains selection on Shift during group manipulation ([workshop description](https://steamcommunity.com/sharedfiles/filedetails/?id=730936602), [controller](https://github.com/pardeike/Achtung2/blob/master/Source/Controller.cs)). Hive already uses Shift/Ctrl for actor set selection (`view.js:83-97`) and Shift on a right-click tree to choose queued rather than direct Chop (`view.js:58-68`, `main.js:281-287`). Preserve those established meanings. For the requested Draft/Go slice, provide one Go target and a cancel/replace action; add Shift-waypoint queuing only with numbered visible waypoints and an authoritative ordered command/result. It must not compete with box/additive selection on the same gesture.

5. **Use area operations for explicit bulk intent, not a hidden right-click side effect.** Allow Tool advertises selecting similar things, urgent hauling, and map-wide tool extensions; Achtung exposes multi-colonist work and line movement rather than turning every click into a bulk command ([Allow Tool](https://github.com/UnlimitedHugs/RimworldAllowTool), [Achtung description](https://github.com/pardeike/Achtung2/blob/master/ModDescription.md)). Hive’s box selection is already a separate idle drag gesture, and build/Chop use tool gestures (`main.js:292-363`). Retain that split: box drag changes persistent selection; a drawing tool creates a previewed designation; right-click acts on the current selection/target. Any later “work this area” must render its eligible targets and command receipts, rather than inheriting a surprising area from a context click.

These sources do not establish a reason to import C# mod behavior, add formations, or copy configured right-click modes. They support the immediate Work/Draft decision: selection persists, Draft gates Go, and ordinary work remains separate from shared designations and any future persistent override.
