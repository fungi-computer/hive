# Connected cave features: first isolated source contract

2026-09-08. Root owns only this new directory. Frozen volume-query-v1, volume-v2, gas-binding evidence and all tracked game/lab callers remain unchanged.

The existing generated material owner has coherent volumetric cavities but deliberately protects the upper three solid layers. It therefore cannot generate a surface entrance. This candidate adds one bounded, seeded **pit and sloping gallery** feature recipe to the same base-material query used by point reads, brick decoding, edit normalization and save validation. It does not add a parallel carve overlay or second terrain inventory.

The recipe is geometric: intersecting capsules in physical metres plus a terminal chamber, sampled at voxel centres. Horizontal cells are 1 m and vertical cells 0.54 m. Positive-radius junction overlap must yield actual six-face-connected sampled void, not just intersecting continuous centre lines. A pit entrance is intentionally not a proven walkable human path or a staircase. Generated void is not a declaration of dry air, water quantity, or liquid initialization.

Each 128 m feature region gets one deterministic candidate from a separately named seed namespace. A bounded jitter leaves the feature inside its owner region. The entrance is placed relative to that exact column's physical bed, above the sea datum by a declared dry-land margin; unsuitable candidates are absent, not resampled until a success. The finite world has 32 by 32 possible owner regions; queries never enumerate all of them. Feature IDs depend on seed, recipe and owner region, never query/chunk order. Clipped references keep the same ID.

The geometric footprint is bounded inside its region, so a column needs only its own region's candidate. The feature owner hides centreline primitives, material membership and a bounded disposable descriptor cache. The generated material owner asks for a column query once and uses it for all vertical cells. Feature diagnostics return snapshots for inspection; they do not mutate geometry. Old cavity noise keeps its exact legacy sample namespace so adding a named entrance component cannot accidentally reroll all old caves.

The combined recipe becomes v3 and saves bind its complete definition. Schema structure can remain v2 because it still records sparse material overrides, but v2-world identity is not silently changed on load. Old readers/candidates remain available; no production migration is attempted. The ordinary sparse edit, compare-and-set, no-op, restore, eviction and alias rules remain one owner.

Before any broad run, inspect the first shape. The fixed proof budget is under 10 seconds for a few predetermined land/negative/chunk-boundary regions: candidate work bounded by region cache; feature centreline and all six-face connectivity checked using actual material reads; geometric metric checks; equal point/brick bytes across order and eviction; old base bytes outside feature bounds; source/world identity and file reload with a filled entrance cell; foreign recipe rejection. The fixtures may identify an absent feature honestly, never hunt arbitrarily until a test passes. Any visual presentation goes through Game Delivery after source acceptance; no new renderer or gameplay scope is implied.

Independent first-shape review accepted the owner composition and required vertical coordinate admission in every exposed column predicate, including empty columns; that correction is applied before the fixed proof. The entrance dry-margin check is only on the entrance column. Gallery/chamber intersection with outside terrain is allowed and reported; this is not a guarantee that every carved cell is subterranean or dry.
