The checked column anchors are `source-v2/soil.mjs:createSoil/at/unsaturatedHead`, `geometry.mjs:stockAt/guessHeads`, `solve.mjs:faceLaw/evaluate/eliminateConservation/normalizeWetBoundaryHeads/closureMetrics`, and `column.mjs:initial/validate/advance/encode/decode`. Its actual qualifier proves rigid-pore finite mass, wet/dry boundary storage, anchored saturated pressure, paired fluxes and aligned restart. These laws survive; pressure and iteration aids do not become saved water.

The new region **directly imports the accepted createSoil implementation**, rather than copying retention or assigning a soil tag a new inventory. Each porous voxel has a stable cell ID, one validated soil definition ID and one canonical water mass. This enables a synthetic low-K layer as definition data while preserving the same density/porosity/retention law. Definition keys/cells/reservoirs/ports are normalized into stable order before identity construction.

`geometry.mjs` compiles one finite connected graph from explicit signed voxel cells, actual1m/.54m/1m metrics, closed faces and finite reservoir ports. It creates **no water**. `faces.mjs` is the extracted series-resistance/Darcy/analytic-derivative owner; `residual.mjs` composes storage and each oriented face into the same mixed mass residual, now in all3axes. The full graph solver will consume this representation; it will not instantiate an independent column for each x/z coordinate.

The frozen old column remains a numerical oracle. A new one-cell-wide graph uses the **same new graph solver** and must reproduce the column physical laws before new lateral cases. The old private chain residual/prefix reconstruction is not another proposed production runtime. After both consumers are accepted, root can choose the actual common source move/import migration; this study does not mutate a frozen reference merely to make it look unified.

## Metric and geometry ownership

The current actual voxel recipe is `worldgen/volume-v2/voxel-world.mjs`, `RECIPE.units`: horizontal1m, vertical.54m. Its material enum says air/soil/stone and carries no water quantity. The current gas ND geometry likewise defines world y as vertical and centres `(world+.5)*worldSpacing`; this candidate follows that **coordinate contract**, not the gas fluid-occupancy or pressure owner.

Require caller-supplied spacing `[1,.54,1]` exactly for this packet. Volume=.54m³; x/z-face area=.54m² and centre separation1m; y-face area1m² and separation.54m. Internal resistance uses half each adjacent cell's spacing divided by its own K. At a boundary face, the accepted column quadrature uses quarter spacing at the soil centre and quarter at the trace, with the **adjacent soil's** constitutive definition on that face. A boundary trace does not create porous volume.

Cells have global integer x/y/z; a canonical face is `(axis, integer face anchor)` oriented toward increasing axis, independent of cell insertion. All missing neighbours must be explicitly covered by the descriptor's `exterior:'closed'` policy or a named finite reservoir port. There is no implicit ambient/infinite groundwater head. Interior closed faces are explicit and duplicate/unknown faces reject. Ports may only occupy actual exterior faces.

Each finite reservoir owns one water mass and area, with `M=rho*A*max(h,0)` relative to its port plane. A reservoir may bind several ports **only at the same physical elevation**; its base is derived from that common plane. This covers a pond over a level top face group and a same-height lateral source/sink, without pretending a dry tank supplies a higher submerged aperture. Multi-height/open-channel water geometry requires the later actual free-water owner. The same reservoir mass cannot be copied per port. Boundary K is evaluated separately through each adjacent soil definition, so one tank may contact different soils without adopting a fictitious single soil type.

**Dry transitions are supported only for single-port reservoirs.** Canonical validation rejects an empty multi-port reservoir; every trial multi-port head must stay strictly positive. A zero-stock reservoir with several suction-pressure ports could otherwise pass water between soils without containing any water. This candidate does not claim a physical dry-manifold law. The multi-port series/parallel and 3D finite-plane fixtures remain strictly wet; no quantity floor keeps them wet artificially.

Public compiled arrays/records/definition snapshots are deeply frozen. No mutable input Map, coordinate array or material callback is retained. Stable IDs determine node, face, reservoir, adjacency and tree order; chunk/caller enumeration cannot choose a pressure guess, tree or stock correction. The entire admitted graph must be connected. Disconnected regions and physically unanchored saturated components reject explicitly in this first scope, rather than receiving hidden gauges/storage.

## Numerical choice and bounds before implementation

Keep backward Euler and the actual mixed storage difference. Use the full analytic Jacobian, differentiating storage and both conductivity/resistance endpoints. This Jacobian is generally **nonsymmetric**: neither the gas PCG nor an SPD claim applies. First reference uses deterministic dense partial-pivot LU for at most64 soil nodes +8 finite reservoirs =72unknowns. Pivot ties use stable row order. Recheck `J*delta+R` from the original physical storage/face derivatives after factorization, before line search.

Why this first choice: it extends the already-checked Newton derivatives without adding a convergence-sensitive Krylov/preconditioner owner. The cost is explicitly cubic and is **not a large-world performance claim**. One in-place Float64 LU array at72² is41,472bytes, plus O(N+faces) physical coefficients/vectors and JS metadata; if an implementation retains a second dense matrix it must report that extra41,472bytes. No full sparse framework. Per-request limits: <=72unknowns, <=384active faces, <=512accepted steps, <=64Newton iterations/attempt, <=18line-search trials/iteration, <=12halvings, <=250000residual evaluations and <=30million counted trailing-matrix update operations. Time/physical head/dry envelope and mass tolerances start with the accepted column values. Any budget failure returns no committed partial state.

A modified-Picard solve would freeze K and yield a storage diagonal plus symmetric weighted Laplacian when physically anchored; that could later justify a carefully owned SPD solve. It changes the nonlinear iteration and can converge slowly or fail around wet/dry transitions. It is deferred until the direct reference provides residual and cost evidence. No generic matrix callback/event/plugin layer is being introduced to prepare that alternative.

Each attempted step deterministically rebuilds heads from canonical masses: inverse retention at strictly unsaturated cells; canonical M/(rho*A) at wet reservoirs. `guess.mjs` sorts the actual seed node IDs, then runs multi-source breadth-first propagation through the stable adjacency. Each unanchored node receives its first reached seed's total head minus its own elevation. Only this numerical initial iterate is projected into its existing branch and definition envelope: saturated soil h>=0, dry single-port trace h<=0. No mass changes. The traversal visits each node once and each directed adjacency once; counters include those actual visits and projections. It cannot read an unsaved last pressure. Absolute saturated pressure requires a physical wet/unsaturated anchor. Saves contain geometry/definition/solver identity, masses and clock/balance facts, not h, LU, a tree or a pressure cache.

`newton.mjs` uses the full differentiated storage and harmonic-resistance Jacobian from the current iterate; no coefficient is frozen as modified Picard. Each LU direction is checked against those original physical coefficients. A line candidate must remain inside every node's physical head envelope and reduce the original max absolute mixed residual by the declared Armijo factor 1e-4, or reach 1e-10 kg. Up to 18 factors 1,1/2,... are tried. The solver permits at most 64 iterations, then reports a `ConvergenceFailure`. A retry halves only for that named nonlinear/closure failure, at most 12 times, and never below 1e-6 s. No relaxation of physical acceptance accompanies retries.

**Fatal versus retriable policy:** invalid input/identity, unsupported unanchored/dry multi-port state, exhausted work budget, singular/nonfinite LU or failed original-Jacobian direction residual reject the whole request immediately. A singular direction is deliberately not treated as an invitation to halve: the first reference has no tested recovery law for it. Only bounded Newton reduction/iteration or post-closure failure can halve. Every rejected numerical stage is recorded; on any final failure the input remains unchanged and local progress is explicitly marked uncommitted. The caller includes a hard evaluation-budget failure after one locally accepted step.

`linear.mjs` retains one N² Float64 matrix plus O(N) right-hand-side/direction and O(N+faces) original coefficients. `matrixUpdates` counts completed trailing `A[row,col] -= factor*A[pivot,col]` operations, with a hard bound checked before each operation; denied work is not counted as completed. Separate counters expose matrix builds/assembly adds, pivot comparisons/swaps, factor divisions, right-hand-side updates and back-substitution operations. `peakDenseBytes` is the matrix alone, not total JS/process memory. Evaluation budgets count admitted actual residual calls. Successful receipts retain all accepted heads/masses, one actual face ledger, tree corrections, wet-head normalization deltas, residual maxima and rejection diagnostics. These are evidence, not saved physical state.

## Cycles change conservation closure

The column's prefix reconstruction is invalid on a cyclic voxel graph. After Newton convergence, keep its bounded constitutive target masses; if needed eliminate one strictly mobile stock from total conservation using stable candidate-branch order. Normalize all positive reservoir heads from canonical stock, preserving dry traces. Start from **actual Darcy transfers on every face**, not zero flows.

Let B give positive outward incidence and `T=rho*dt*Q`. The remaining local continuity discrepancy is `r=M_old-M_new-B*T`. A deterministic stable-ID spanning tree accumulates each subtree residual. Correct only tree edges with that subtree amount and orientation; **chord transfers remain the evaluated Darcy transfers**, preserving physical cycle-flow information. This is a small conservative residual correction, not a new pressure solution. Require total compatibility, bounded correction on every face, exact stock bounds and the same post-closure constitutive/Darcy/paired-transfer/complementarity tolerances. Every active face gets one signed paired receipt. No quantity clamp, hidden conductivity floor, mean-subtracted source or arbitrary circulation.
