# Behavior-neutral finite gas module decomposition

This sibling preserves the accepted physics, public VERSION, canonical identity, tolerances, timestep/retry/step limits and all arithmetic/reduction order of `../finite-low-mach-v1/`. The original candidate, its first proof, Fallow output and final handoff inventory remain frozen. Only `projection.mjs` and `finite-gas.mjs` numerical source change; geometry, thermodynamic definitions, transport and the Boussinesq predictor/caller remain the same owners.

The old pressure function joined input admission, sealed-component compatibility, numeric coefficient assembly, PCG, velocity correction and all-cell residual admission. Each now has an internal function that owns those calculations. A single private workspace still owns reusable topology and typed-array scratch. Numeric coefficients rebuild at each actual solve, preserving count order. Component tracing preserves the old DFS order and existing gauge-pin checks. The public `project` coordinates those complete operations; there is no parallel pressure equation or generic solver framework.

The old finite `advance` joined request validation, bounded RK trial, accepted-state averaging and receipts. `admitAdvance` owns checked physical interval/source/work limits. `rungeKuttaTrial` owns only the original two Euler stages, named intermediate-envelope/CFL retry and halving budget. `acceptTrial` alone installs the validated averaged candidate and accumulates paired face/cell receipts and reported extrema. Its scratch record remains private to one synchronous advance and is discarded on rejection. Retry totals move from the outer loop to the trial/accept boundary; bounded integer addition is exact. Euler physics, validation, source treatment, state freeze/codec and thermodynamics are unchanged.

The first numerical run has a fixed 30-second outer budget and includes the existing seven physical-law groups, then exact old/new complete outputs and work diagnostics for rest, heating, CFL reduction, intermediate envelope reduction, both supported inert definition choices and the actual Boussinesq consumer. It checks direct projection, variable mobility, public transport, exact cross-version save/reload, and rejects malformed/unsupported requests with the same error class/message and unchanged caller input. Saved dt4/2/1 states and aggregate receipts are also compared byte-for-value against the original evidence. The original handoff inventory is checked before and after; reference modules are called read-only and original proof scripts are never imported or rerun.

Fallow is inspected on the new source after that qualification. Public entrypoints and limits remain exported; no suppression, valid-export removal, physics expansion or wider game changes are authorized. Exact output equality is a finite regression proof, supplemented by source review; it is not a claim that all possible inputs were exhaustively enumerated or that the physical model is complete 3D finite gas.
