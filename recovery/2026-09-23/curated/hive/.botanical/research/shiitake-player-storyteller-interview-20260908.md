## Roles and first observable loops

**AI player / hired familiar.** Act using the account's own people, or an explicit delegation from a customer. The same resources, work permissions, paths and time apply. First proposed loop: one ready mugwort, a Garden-enabled member, and a human-started task to harvest it. A supported Shiitake Session prompt uses its existing `execute` tool to discover a host-supplied bounded game read and command capability. It reads the current herb/job facts, submits the existing shared Harvest intent, receives admission status, then observes the real herb removal and physical bundle produced by ordinary simulation. Test retried intent, wrong scope and human pause/withdrawal. Account-owned and hired control should reuse this one game boundary.

This needs a small future authenticated observation/admission/receipt join; those tools do not exist in Hive now. It proves one model-directed action, not paid billing, unattended hosting or nation-scale performance. Offline autoplay later requires the accepted authoritative host/clock and durable effects; keeping today's browser hidden cannot provide it.

**Core storyteller, no LLM dependency.** Ordinary game code selects eligible physical incidents, targets, timing and magnitude using configured profiles and actual history. The first proposed proof selects a visiting-party incident or defers based on real home readiness and recent pressure. Game admission revalidates and persists one event; the visitor visibly enters and ordinary simulation determines what happens. A second starting history demonstrates a different pacing decision, and retry/reload must not duplicate the party. This requires a real arrival/lifecycle owner; recruiting already-present Sedge is not arrival. Narration may accompany the event but cannot substitute for it. The linked primary-source study covers content mixing, adaptation/recovery, eligibility and travel continuity.

**Occasional Shiitake event director.** Levi wants larger interventions, perhaps a couple a day or more, including a concert with Shiitake controlling a dragon. Cadence, scope and day clock remain tuning questions. Shiitake proposes supported events and can direct several bounded cues within an admitted event; normal simulation executes physical consequences. First prove one optional variation/timing decision through the same visitor primitive, sharing history/admission with the core storyteller. Its absence must not stop routine storytelling, and late responses cannot stack a stale incident on top of a newly busy home. A performance and its constituent model calls are different scheduling units. Event authority stays separate from a player account even when its persona is the same Devil or familiar.

**Player chat and delegated control.** A small in-game LLM window provides advice and lets a person request actions or authorize ongoing play while away. Advice does not itself submit work; requested/delegated actions use ordinary player authority. Show the active control mode, allow human takeover/stop, and report game outcomes from real receipts. The existing harvest-loop proposal above is the first useful action proof. Offline host, UI and billing joins are not implemented by this plan.

**The game is a channel, latest direct correction.** Hive provides the game channel, in the same sense that Discord will be another channel. Botanical owns Discord and shared channel infrastructure; the game portfolio has no Discord research or adapter responsibility. The game supplies permitted committed observations, such as an actual attack, to the bound player Agent. A response may be in-game speech or an authorized action. Preserve physical occurrence, delivered observation, conversation context and resulting action as different facts with explicit authority. Botanical's retained channel-contract anchors are pending; Hive will consume that shared capability rather than recreate it.

World pacing should offer opportunities on meaningful milestones/exceptions with cooldowns and pressure/recovery budgets. No per-tick model call, no retroactive command during an offline interval, and no LLM decision inside the deterministic step. Ordinary storytelling and NPC behavior continue without a model response. Delayed model work must not build a backlog of concerts/crises to discharge later. The exact event catalog and event-specific continuation remain open.

Levi remains product authority. Human account owners issue/revoke their delegations; server/world owners set permitted rules and event difficulty. Game authority validates both roles. Botanical owns identity/delegation/Session/goal/billing capability fit, with Hive checking the actual grant at game admission. Model persona and purchased entitlement do not themselves confer extra verbs.
